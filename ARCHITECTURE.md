## 5. User Journey Maps

### Journey 1: New Patient Discovery → Appointment
1. Land on Hero (5 sec trust build)
2. Scroll to About (emotional connection)
3. Explore Microscopic Dentistry (education)
4. View Technology (proof)
5. Check Testimonials (social proof)
6. Book Appointment (conversion)

### Journey 2: Specific Procedure Research
1. Land on specific procedure page
2. Read comprehensive AEO content
3. View before/after gallery
4. Watch related videos
5. Read FAQ
6. Book Consultation

### Journey 3: Emergency / Urgent Care
1. Land on page
2. Immediate CTA visible
3. Phone number prominent
4. Direct booking form

## 6. Conversion Funnels

### Primary Funnel: Appointment Booking
- Hero CTA → Micro-commitment
- Scroll engagement → Trust building
- Multiple CTAs throughout
- Form with minimal friction
- Multiple contact methods

### Secondary Funnels
- Phone Call
- WhatsApp/Instagram DM
- Email Inquiry
- YouTube → Website
